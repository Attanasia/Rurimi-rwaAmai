##Overview

Rurimi rwaAmai meaning "the mother tongue" in English is an AI-powered Shona language learning companion. It helps users learn Shona through interactive translations, combining RAG(Retrieval-Augmented Generation) with a large language model.

##Freatures 

- 1000+ verified English-Shona translation pairs
- Fast responses using Groq API
- Handles greetings, numbers, days, common phrases
- Supports combined phrases (e.g., "tomato and onion")
- RAG pipeline with ChromaDB vector database

##Setup Instructions

- Clone or download this repository
- Create and activate virtual environment using requirements.txt
- Set up your API, l used Groq API for this project
